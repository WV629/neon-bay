Neon Bay is a complete 2D top-down open-world crime game in the spirit of GTA 6, built as plain static files with zero network requests. Explore a seeded, deterministic fictional city on foot and by car, steal cars, outrun the Neon Bay PD across a 0–5 star wanted system, fight armed crews, and run five story missions for the fixer Mara Voss — from a car theft at the Docks to the Bayfront Bank hold-up. Traffic follows the street grid, pedestrians flee gunfire, and the city shifts from dusk to night with lit windows, neon signs, a live minimap, synthesized WebAudio music and engine/siren sounds, particles, screen shake, and localStorage saves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no install, no network.
